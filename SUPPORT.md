# Getting help

Thanks for your interest in the Salalihini Sandeshaya project. Here is where to go for what.

| I want to... | Go here |
| --- | --- |
| report a **wrong word or a confusing explanation** in a verse | [Content correction form](../../issues/new?template=content_correction.yml) |
| report a **bug** (broken, slow, or ugly on my device) | [Bug report form](../../issues/new?template=bug_report.yml) |
| suggest an **idea** | [Feature request form](../../issues/new?template=feature_request.yml) |
| **contribute** content or code | [CONTRIBUTING.md](CONTRIBUTING.md) |
| report a **security problem** | [SECURITY.md](SECURITY.md) (privately, please) |
| ask how something works | open a [Discussion](../../discussions) if it is enabled, otherwise an issue |
| report behaviour that breaks the **code of conduct** | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

## Before you ask

- Check the [README](README.md): it covers setup, scripts and the project layout.
- Search the [existing issues](../../issues); your question may already be answered.
- For poem content, remember the explanations are learners' aids written by an engineer, not by a scholar.
  Corrections are exactly what we are looking for.

## Please note

This is a volunteer project. Replies may take a few days. We are grateful for your patience, and for your help.
